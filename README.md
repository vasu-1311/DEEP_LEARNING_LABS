# Deep Learning Fundamentals & Architectures

This repository serves as my hands-on workspace for Deep Learning. It tracks my progress from foundational neural network concepts to building, training, and optimizing deep learning models for real-world tasks.

---

## 📌 Core Concepts Covered

### 1. Neural Network Foundations
- **Artificial Neural Networks (ANN):** Perceptron, Feedforward Architectures, Forward & Backward Propagation.
- **Math Behind DL:** Gradient Descent variations, Loss Functions (MSE, Cross-Entropy), and Activation Functions (ReLU, Sigmoid, Softmax).

### 2. Optimization & Regularization
- **Optimization Algorithms:** SGD with Momentum, RMSprop, Adam.
- **Overfitting Mitigations:** L1/L2 Regularization, Dropout layers, Early Stopping, and Batch Normalization.

### 3. Computer Vision & Sequential Models
- **Convolutional Neural Networks (CNN):** Convolutions, Pooling, Feature Maps, Image Classification.
- **Recurrent Architectures (RNN / LSTM / GRU):** Sequence modeling, Time-Series analysis, and NLP fundamentals.
